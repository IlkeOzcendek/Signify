# Synthetic interface examples

These four images contain artificial pen strokes created for the Signify interface demonstration. They do not reproduce a real person's signature.

For manual comparison:

- Use `synthetic_reference_1.png`, `synthetic_reference_2.png` and `synthetic_reference_3.png` as references.
- Use `synthetic_questioned.png` as the questioned image.

The marks are deliberately similar to demonstrate the comparison workflow. They are not a dataset for training, calibration, benchmarking or claims about genuine-versus-forged signature performance.

Preprocessing previews work without trained weights. Producing a model result requires [compatible local checkpoints](../../docs/MODELS.md).
